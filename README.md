## About

The **M5Stack CoreS3** is an ESP32-S3 based programmable IoT controller with a 2" capacitive touch display, built-in sensors and expandable ports. This repository collects working example programs in two flavors:

- **Arduino IDE** — C/C++ sketches using the M5CoreS3 library
- **UiFlow 2.0** — MicroPython blocks/code via the [UiFlow 2.0 web IDE](https://uiflow2.m5stack.com/)

📺 Step-by-step video tutorials for these examples are on our [YouTube channel](https://www.youtube.com/@Fusion_Automate).

## Examples

| # | Example | Platform | What it demonstrates |
|---|---------|----------|----------------------|
| 1 | Display Hello World on Screen | Arduino IDE | Draw text on the built-in touch display |
| 2 | Display QR Code on Screen | Arduino IDE | Render a QR code on the display |
| 3 | Hello World | UiFlow 2.0 | First MicroPython program on CoreS3 |
| 4 | RTC Digital Clock | UiFlow 2.0 | Read the onboard RTC and show time on screen |
| 5 | Web API Digital Clock | UiFlow 2.0 | Fetch time from a web API and display it |

## Getting Started

- **Arduino IDE**: install the M5Stack board package and `M5CoreS3` library — see the official docs at [docs.m5stack.com](https://docs.m5stack.com/), then open any sketch folder and upload.
- **UiFlow 2.0**: open [uiflow2.m5stack.com](https://uiflow2.m5stack.com/), connect your CoreS3, and import the `.py` files from the `UiFlow 2.0/` folder.
